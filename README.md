# ESP32 Projects

A collection of my ESP32 projects focused on embedded systems, electronics, automation, and IoT.

This repository contains completed projects, ongoing developments, and future experiments built around ESP32 microcontrollers.

## Completed Projects

- **Home Assistant Light Controller** — A physical controller for a smart light built with an ESP32-C3, a rotary encoder and a push button. The button switches the light on and off, the encoder sets brightness, and pressing the encoder toggles warm and cool white. Runs on ESPHome.  
  [View Project](./HA-Light-Controller/README.md)

## Ongoing Projects

- **ESP32 Touchscreen Control Panel** — A touchscreen-based control panel built with an ESP32 and a 2.4-inch TFT display, featuring an interactive menu, customizable UI themes, and server monitoring through a local HTTP API.  
  [View Project](./Touch-Panel/README.md)
